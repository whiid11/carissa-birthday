## 🌐 Cara 1: Deploy ke Vercel (Paling Direkomendasikan — Cepat & Otomatis)

Deploy ke Vercel sangat direkomendasikan karena URL-nya bersih, memiliki CDN global yang sangat cepat saat dibuka di HP, dan mendukung SSL otomatis gratis:

### Langkah Deploy ke Vercel:
1. Pastikan project sudah di-push ke GitHub (ikuti langkah di bawah).
2. Buka [vercel.com](https://vercel.com) lalu login menggunakan akun GitHub Anda.
3. Klik tombol **"Add New..."** lalu pilih **"Project"**.
4. Di daftar repository GitHub Anda, pilih repo **`carissa-birthday`** lalu klik **"Import"**.
5. Pada bagian *Build & Development Settings*, biarkan default (karena ini web statis, tidak perlu build command).
6. Klik **"Deploy"**.
7. Dalam 15-30 detik, website Anda sudah online dengan domain instan yang cantik, contoh:
   👉 **`https://carissa-birthday.vercel.app`**

## 🌐 Cara 2: Deploy ke GitHub Pages

1. **Buat Repository Baru di GitHub:**
   - Buka [github.com/new](https://github.com/new).
   - Beri nama repository (misalnya: `carissa-birthday`).
   - Pastikan pilih **Public**.
   - Klik **Create repository** (jangan centang "Add a README file").

2. **Hubungkan & Push dari Terminal:**
   Buka PowerShell / Command Prompt di folder `F:\birthday`, lalu jalankan:
   ```bash
   git remote add origin https://github.com/<username-anda>/carissa-birthday.git
   git push -u origin main
   ```

3. **Aktifkan GitHub Pages (1 Klik):**
   - Buka halaman repository di GitHub.
   - Masuk ke tab **Settings** (di menu atas) > pilih menu **Pages** (di sidebar kiri).
   - Di bagian **Branch**, pilih **`main`** dan folder **`/(root)`**, lalu klik **Save**.
   - Tunggu sekitar 1–2 menit, link website akan aktif di:
     👉 **`https://<username-anda>.github.io/carissa-birthday/`**
