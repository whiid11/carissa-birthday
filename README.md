## 🚀 Cara Melihat Website di Komputer Anda (Preview Lokal)

Anda cukup klik ganda (double-click) file **`index.html`** di folder `F:\birthday`, dan website akan langsung terbuka di browser Anda (Chrome, Edge, Safari, dll.).

Atau bisa menggunakan server lokal Python:
```bash
python -m http.server 8000
```
Lalu buka browser di: `http://localhost:8000`

## 🌐 Cara Deploy ke GitHub Pages (Agar Bisa Dibuka Online di HP Carissa)

Website ini **100% murni statis** (HTML, CSS, JS tanpa backend), sehingga sangat mudah dan gratis di-deploy ke GitHub Pages dalam hitungan menit:

### Cara 1: Menggunakan Terminal / Git (Paling Cepat)
1. Buka PowerShell atau Git Bash di folder `F:\birthday`.
2. Inisialisasi Git:
   ```bash
   git init
   git add .
   git commit -m "Happy 21st Birthday Carissa Putri Maharani"
   ```
3. Buat repository baru di [GitHub](https://github.com/new) (misalnya beri nama `carissa-birthday` dan pastikan diset **Public**).
4. Hubungkan dan push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<username-anda>/<nama-repo>.git
   git push -u origin main
   ```
5. Buka repository Anda di GitHub, lalu klik tab **Settings** > **Pages** (di menu sebelah kiri).
6. Pada bagian **Branch**, pilih **`main`** dan folder **`/(root)`**, lalu klik **Save**.
7. Tunggu sekitar 1-2 menit, link website akan langsung aktif! Link-nya akan berbentuk:
   `https://<username-anda>.github.io/<nama-repo>/`
